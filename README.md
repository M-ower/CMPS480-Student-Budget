# Student Budget and Spending App

A simple web application designed to help college students track their income, expenses, and spending habits.

## Current Features

- Add income and expenses
- Categorize transactions
- View total income
- View total expenses
- View current balance
- View transaction history
- Clear transaction history

## Technologies

- HTML
- CSS
- JavaScript

## Future Features

- Monthly budgets
- Spending charts and analytics
- User accounts
- Database storage
- Authentication and security

## Project Status

This is the first version of the project. More features will be added as development continues.
